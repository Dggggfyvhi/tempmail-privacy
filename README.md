# 私密通 · 聚合临时邮箱 & 手机

一个单文件 HTML，聚合两个隐私保护渠道，**不收集、不上传任何信息**：

- **临时邮箱**：基于 [mail.tm](https://mail.tm) 开源 API（浏览器直连，无 key）。
  点「获取邮箱」→ 复制地址去网站注册 → 验证码自动出现在下方收件箱，
  点信件查看全文，新邮件会有红色小消息提示。
- **临时手机号（+86）**：基于 [sms-online.cc](https://sms-online.cc) 公开接码页。
  选国家 → 取免费号 → 复制去注册 → 点「刷新短信」看验证码。

## 直接部署

GitHub Pages（本仓库）：https://dggggfyvhi.github.io/tempmail-privacy/

直接双击打开 `index.html` 即可（邮箱功能需要联网访问 mail.tm）。
